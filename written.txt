a. An adversarial sequence of points can be (1/3,1/3), (1/6,1/6), (1/12,1/12) and so on.
   These points approach the origin causing splits along the same branch and making the tree become a list.

   Example:
   querying (0.7,0.7) takes O(1) time because it is an empty quadrant near the root
   querying (0,0) takes O(n) time because it traverses the entire branch

b. Inserting more than 8 identical points causes repeated subdivision because all points
   belong to the same quadrant. This can be prevented by setting a maximum depth and allowing nodes
   at that depth to exceed their capacity

c. Translation can move objects into different quadants but translating the grid along with objects
   preserves the tree structure. Rotation can change the positions and bounding boses of objects which causes them
   to move into different quadrants. Quadtrees are good for static scenes but doesnt work as well for scenes with a lot of 
   large movements or rotations
